# RWServer

На вход поступают читатели и писатели, во время чтения, если есть ожидающие писатели, то новые читатели не могут войти. После выхода из чтения последнего читателя возобновляются ожидающие потоки с приоритетом для писателей. Во время записи читатели блокируются, остальные писатели ожидают завершения записи, также предотвращается голодание, когда писатели постоянно ожидают завершения чтения, путем увеличение числа числа ожидающих писателей до окончания записи (дается приоритет). После завершения последнего писателя возобнавляют работу оставшиеся читатели.
